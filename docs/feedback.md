# R&D Monitor 회의 피드백 정리

> 회의에서 나온 피드백을 정리하고, 현재 프로젝트에서 수정/확인이 필요한 작업 목록으로 재구성한 문서.

## 1. 공고 수집 범위 확대

- 현재는 진행 중인 공고만 수집하고 있음. 마감된 공고도 일정 기간 함께 조회할 수 있도록 범위 확대 검토.
- 기준(안): 최근 3개월 이내 마감된 공고까지 함께 불러오는 방향.
- 마감 공고와 진행 중 공고는 상태값으로 명확히 구분되어야 함 (예: `진행중` / `마감` / `기한미정`).

- 크롤링/API 연동 여부 및 수집 로직 확인 필요.
- 실제로 데이터 누락이 발생하는지 테스트 후 수정.

## 3. 저장한 공고 접근성 개선

- 사용자가 저장한 공고를 따로 확인하기 어려운 상태.
- 대시보드의 "저장한 공고" 영역 클릭 시 저장 목록 화면으로 이동하도록 개선.
- 마이페이지 또는 홈 화면에서도 저장 공고를 쉽게 확인할 수 있도록 구성.
- 핵심은 저장 기능 자체보다 저장 후 "다시 찾아가는" UX를 명확히 하는 것.

## 4. 알림 중복 발송 여부 확인

- 동일 공고에 대한 알림이 중복으로 재발송되는지 확인 필요.
- 공고 ID, 키워드, 알림 유형 기준으로 중복 발송 방지 로직 점검.
- 아래 알림 유형별로 각각 확인:
  - 신규 공고 알림
  - 키워드 매칭 알림
  - 마감 임박 알림

## 5. 전체 UX 플로우 점검

- 모든 버튼이 정상적으로 작동하는지 확인.
- 단순히 링크 연결 여부뿐 아니라, "이 버튼을 눌렀을 때 이동하는 화면이 사용자의 기대와 맞는가?"까지 검토.
- 불필요한 이동 단계나 헷갈리는 버튼 명칭도 함께 수정.

**주요 사용자 흐름**
- [ ] 공고 탐색 → 상세 공고
- [ ] 공고 저장 → 저장 공고 확인
- [ ] 키워드 등록 → 매칭 공고 확인
- [ ] 알림 클릭 → 해당 공고 상세
- [ ] 대시보드 KPI / Quick Action → 적절한 목록 화면 이동

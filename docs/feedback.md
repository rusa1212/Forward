> 회의에서 나온 피드백을 정리하고, 현재 프로젝트에서 수정/확인이 필요한 작업 목록으로 재구성한 문서.

## 1. 공고 수집 범위 확대

- 기준(안): 최근 3개월 이내 마감된 공고까지 함께 불러오는 방향.
- 마감 공고와 진행 중 공고는 상태값으로 명확히 구분되어야 함 (예: `진행중` / `마감` / `기한미정`).

- [x] 누락 확인 시 원인 파악 및 수정
  - (1) 조회기간을 API 상한(31일) 이하 구간으로 쪼개 병렬 호출 후 병합하도록 수정

    25,086건 정상 수집. 검증 도중 구간 하나가 API 호출 한도(429 Too Many Requests)에
    걸렸는데, 그 구간만 로그를 남기고 스킵되고 나머지 구간은 정상 반환되는 것까지
    실제로 확인해 방어 로직이 의도대로 동작함을 검증함.

## 4. 알림 중복 발송 여부 확인

## 5. 전체 UX 플로우 점검

- 모든 버튼이 정상적으로 작동하는지 확인.
- 단순히 링크 연결 여부뿐 아니라, "이 버튼을 눌렀을 때 이동하는 화면이 사용자의 기대와 맞는가?"까지 검토.
- 불필요한 이동 단계나 헷갈리는 버튼 명칭도 함께 수정.

# 1차 기업 미팅 전후 개발 정리

> 기준: `docs/5th_wk_1차_작업정리.md`(커밋 `f7c6f41`~`55b32d0`, PR #10 머지 `169cc5f`, 2026-08-28)까지가
> **1차 기업 미팅 전** 개발 내용이고, 그 다음 커밋(`e6bbcab`, 2026-08-31)부터 현재(`HEAD`, 2026-09-12)까지가
> **1차 기업 미팅 후** 진행 상황이다.
>
> 뒤쪽 "PPT 슬라이드 구성 제안" 절은 1차 기업 미팅 후 작업만으로 발표 자료를 만들 때 참고용.

## 1. 1차 기업 미팅 전 (~2026-08-28)

- **범위**: BE가 먼저 만든 4개 API(회원가입/로그인, 공고 조회, 키워드, 저장공고)를 FE에 처음 연동
- **주요 이슈**: 실제 Supabase `users` 테이블 스키마가 코드 가정(`emp_id`/`email`)과 처음부터 달라 팀 논의 후 새 스키마로 실제 테이블을 맞추기로 결정
- **사고**: DB 스키마를 고치려던 마이그레이션 스크립트가 정책 충돌로 실패 → 라이브 `users` 테이블이 드롭된 채 복구 안 된 상태로 남는 사고 발생 → 사용자가 Supabase SQL Editor에서 직접 복구
- **추가 발견**: 복구 과정에서 실제 DB에 `user_keywords`/`alert_settings`/`notification_logs`가 이미 존재하지만 BE 코드 가정(`keywords`/`saved_announcements`)과 불일치 → FK/UNIQUE 미비 등으로 **미완성 스캐폴딩**으로 판단, 손대지 않고 보류
- **결론적 상태(최종 스모크 테스트)**: 인증/공고 검색·정렬·페이지네이션·상세/키워드 CRUD/저장공고 CRUD API 전부 정상 동작, 사용자별 데이터 격리(FK + API 로직 이중 검증) 확인
- **남은 과제로 명시된 것**: 대시보드 집계 API·키워드 알림 on/off·마이페이지/알림/자동화 연계는 범위 밖(미착수), `JWT_SECRET` 기본값 방치, `user_keywords` 등 DB 스키마 정리는 DB 담당자 협의 필요

## 2. 1차 기업 미팅 후 (2026-08-31 ~ 2026-09-12, 현재)

### 2-1. DB 인프라 교체 — 미팅 전 최대 블로커 해소

- Supabase(Postgres) → **MySQL/MariaDB로 완전 전환** (`e6bbcab`)
  - UUID → CHAR(36), MySQL 미지원 문법(`nulls_last`, `on_conflict_do_update` 등) 대체, 세션 타임존 UTC 고정
  - `back/mysql/schema.sql` 신규 도입으로 `back/supabase/*.sql` 대체
- **Alembic 마이그레이션** 체계 도입 (`b415240`)
- **Docker 기반 로컬 MySQL 환경 + 온보딩 문서** (`5398494`, `c7b25d2`)
- → 미팅 전 "보류" 상태였던 Supabase 스키마 불일치 문제 자체가 DB 교체로 해소됨

### 2-2. 관리자 페이지 / 대시보드 / 검색 기능 확장

- **관리자 페이지** 신규: 사원 명부 관리, 가입자 목록 조회/삭제 (`fe5c6ae`, `069b3c4`)
- **대시보드**: mock 데이터 제거 후 실데이터 연동 → 이후 매칭 추이 차트까지 실 DB 집계로 전환 (`8c0b50e`, `0f72f1a`)
- **검색화면**: 정렬 UI, 키워드별 색상 배지, 수집 출처 컬럼 추가 (`a69f719`, `b58f932`)
- 대시보드/헤더 실사용자 이름 표시, "매칭된 공고 전체보기" 필터 버그 수정 (`2623599`, `fa44b9f`)

### 2-3. 마이페이지 · 알림 · 이메일 발송 자동화 — 미팅 전 "미착수" 범위였던 부분

- **마이페이지 API** 구현 + FE 연동, 헤더 알림 연동 (`99697b4`, `733848f`)
- **알림 저장 구조 + 알림 목록/읽음 API** (`5dc53e8`)
- **알림·이메일 발송 자동화 파이프라인** 구축 (`35c63d9`)
- **알림 설정(alert_settings) API** 구현 + FE 연동(AlertsTab) (`301309a`, `b01f473`)
- **"지금 이메일로 받기"** 즉시 발송 기능 추가 (`bd4aa91`)
- 공고 자동 수집 주기를 **하루 2회로 확대 + 매 실행마다 매칭 메일 자동 발송** (`aa386d5`)
- SMTP 465(암시적 SSL) 지원 — 회사 메일서버 이전 대비 (`704dd23`)
- 알림설정 UX 반복 개선: 키워드별 토글 다수 → 전체 공통 토글 1개로 통합, "자동 발송"과 "지금 바로 받기" 시각적 구분, 하드코딩된 이메일(`kim@company.kr`) → 실제 로그인 계정 이메일로 교체, 최종적으로 한 카드로 통합 (`7b31f19`, `0919f58`, `edf5539`, `b6f2653`, `5cec9cb`)

### 2-4. 전면 UI 리디자인 (redesign v7)

- Claude 디자인 핸드오프(`design_handoff_forward_ui_refresh`) 기준으로 **프레젠테이션 레이어 전면 교체** — 라우트/API/인증/검색·키워드·즐겨찾기 로직은 유지 (`eb5764b`)
  - 디자인 토큰: Forward Blue(#315CFF) + 뉴트럴 시스템, Pretendard 폰트
  - 신규 홈 랜딩 페이지(퍼블릭, 히어로 검색), 공통 GNB/라이트 푸터
  - 대시보드: KPI 4분할, 매칭 추이 차트, 위젯 순서 변경/숨기기(localStorage)
  - 검색: 상태 세그먼트, 컬럼 정렬 테이블, 행 별표 저장, 원형 페이지네이션
  - 마이페이지: 세그먼트 탭, 프로필 2단 레이아웃
  - 관리자: 직원/가입자 세그먼트, 소프트 상태 뱃지

### 2-5. 보안 수정 · 안정화 · 버그 픽스

- `/collect` API **관리자 인증 회귀 수정(P0 보안)**, collect API 관리자 인증 적용 (`d7e1b77`, `3948f9b`)
- 테스트가 개발 DB를 지우던 문제 → **전용 테스트 DB로 분리** (`c4b2fe5`)
- 예외/로그/API 테스트 24건+ 보강, **Postman 컬렉션** 문서화 (`56ecebc`, `3b50a17`, `de2101b`)
- 공공데이터 인증키 중복 인코딩 버그, 대시보드 `newToday` 타임존 버그, 저장공고 `statusLabel` 누락 등 수정
- 접수기간 정보 없는 공고를 **"기한미정" 상태로 분류** (`fc8b4e2`)
- 랜딩페이지 검색바 검색어 미반영 버그 수정 (`94cb9e7`)
- 스케줄러: **서버 시작 시 공고 즉시 1회 수집** 추가 + pytest에서 실제 API 호출 안 되도록 안전처리 (`6813dbc`, `1866ead`)

## 3. 요약

1차 기업 미팅 전은 **"BE-FE 연동 첫 시도 + Supabase 스키마 불일치라는 근본 블로커에 부딪힌 상태"**였다.
미팅 후에는 그 블로커를 **DB를 MySQL로 완전히 교체하는 방식으로 해소**한 뒤, 미팅 전 범위 밖으로 명시했던 기능들
(대시보드 실데이터, 마이페이지, 알림/이메일 자동화, 관리자 페이지)을 순차적으로 완성했고, 최근에는
**UI 전면 리디자인**과 **보안 회귀 수정·테스트 인프라 정비** 등 안정화 작업까지 진행했다.

## 4. PPT 슬라이드 구성 제안 (1차 기업 미팅 후 작업 기준)

발표 스토리라인: "미팅에서 지적된 구조적 문제 해결 → 미착수 기능 완성 → UI 고도화 → 안정화"

1. **타이틀 / 개요**: 기간(2026-08-31~09-12), 목표(미팅 전 블로커 해소 + 남은 범위 완성)
2. **Before 요약 (1장)**: 미팅 전 상태 — 4개 API 연동 완료, but DB 스키마 불일치·대시보드 mock·알림 미착수
3. **DB 인프라 전면 교체**: Supabase → MySQL 전환 배경(스키마 불일치 해소) / Alembic 도입 / Docker 온보딩
4. **관리자 페이지 신설**: 사원 명부·가입자 관리 화면 스크린샷
5. **대시보드 실데이터화**: mock 제거 → 실 DB 집계, 매칭 추이 차트
6. **검색 기능 고도화**: 정렬 UI, 키워드 배지, 수집 출처 표시
7. **마이페이지 & 알림 시스템 구축** (신규 영역 강조): 알림 저장/목록/읽음 API, alert_settings API, 즉시 이메일 발송
8. **이메일 자동 발송 파이프라인**: 하루 2회 수집 + 매칭 메일 자동 발송, SMTP 465 대응
9. **UI 전면 리디자인 (redesign v7)**: Before/After 스크린샷 — 홈 랜딩, 대시보드, 검색, 마이페이지
10. **품질·보안 안정화**: P0 보안 회귀 수정, 테스트 DB 분리, 테스트 24건+ 추가, Postman 문서화
11. **최근 개선 & 잔여 버그 픽스**: 기한미정 분류, 스케줄러 즉시 수집, 랜딩 검색바 수정
12. **다음 단계 / Ask**: (필요 시 남은 과제 — 예: 추가 알림 채널, 성능 최적화 등)

각 슬라이드는 위 2절의 해당 소절(2-1~2-5) 내용과 커밋 해시를 근거 자료로 그대로 활용 가능.
